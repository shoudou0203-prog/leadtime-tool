プライバシーポリシー(leadtime-tool)

最終更新日: 2026年11月25日

1. このアプリについて

leadtime-tool は、開発者本人が自分の Amazon 出品の出荷作業日数を変更するためだけに使う、個人用の Google Apps Script ウェブアプリです。一般の利用者には提供していません。

2. 取得・利用する情報

  • Google アカウント: Apps Script を実行するための認可(外部 API への接続、自動処理のトリガー作成)のみに使います。Gmail、Google ドライブ、連絡先、カレンダーなどの Google ユーザーデータは取得しません。
  • Amazon の接続情報(API の認証情報)と処理ログ: 利用者自身の Google アカウント内の Apps Script のスクリプトプロパティにだけ保存し、外部には送信しません(Amazon の API への接続を除く)。

3. 第三者への提供

取得した情報を第三者に販売・提供・共有することはありません。

4. 削除

Google アカウントの「サードパーティ製のアプリとサービス」からこのアプリへのアクセスを削除することで、いつでも認可を取り消せます。保存された情報は Apps Script のプロジェクトを削除すると消去されます。

5. お問い合わせ

このページを公開している GitHub リポジトリ(shoudou0203-prog/leadtime-tool)の Issues からご連絡ください。
