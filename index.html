leadtime-tool(Amazon リードタイム一括変更)

leadtime-tool は、Amazon.co.jp で自己発送の商品を出品している出品者が、自分の出品の「出荷作業日数(リードタイム)」をまとめて変更するための、個人用の Google Apps Script ウェブアプリです。

できること

  • Amazon の Selling Partner API から自分の出品一覧を取得する
  • 選んだ条件(ステータス・在庫の有無・SKU)に当てはまる出品の出荷作業日数を一括で変更する
  • 変更が反映されたかを読み取って確認する

Google アカウントの利用について

このアプリは開発者本人だけが使うものです。Google アカウントへのアクセスは、Apps Script の実行(外部 API への接続と、1 分ごとの自動処理のトリガー作成)のためだけに使います。Gmail・Google ドライブ・連絡先などのユーザーデータは読み取りません。
